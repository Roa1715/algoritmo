# Algoritmia - Semana 3

Ejercicios de **ciclos** (`while`, `for`), acumuladores, contadores, banderas y
**funciones** en **JavaScript** (Node.js).

| Archivo | Descripción |
|---|---|
| `cajero_parqueadero.js` | Suma cobros hasta ingresar 0 (acumulador y contador) |
| `calificaciones.js` | Promedio, aprobados, máximo, mínimo y bandera de 5 notas |
| `factura_restaurante.js` | Factura con impuesto y propina usando funciones |
| `piramide.js` | Dibuja una pirámide de asteriscos con ciclos anidados |
| `validar_pin.js` | PIN con máximo 3 intentos (PIN de prueba: 1234) |

## Cómo ejecutarlos

Requiere [Node.js](https://nodejs.org) 14 o superior. Cada archivo es independiente:

```bash
node piramide.js
```
