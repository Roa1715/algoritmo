# Algoritmia - Semana 1

Ejercicios básicos de algoritmos en **JavaScript** (Node.js): entrada, salida,
variables y operaciones aritméticas.

| Archivo | Descripción |
|---|---|
| `Saludo.js` | Pregunta el nombre y da la bienvenida |
| `EdadDias.js` | Calcula aproximadamente los días vividos a partir de la edad |
| `PromedioNotas.js` | Promedia 3 notas |
| `Cuenta.js` | Divide una cuenta entre varias personas y calcula la propina (10 %) |
| `Tinto.js` | Muestra la receta para preparar un tinto |

## Cómo ejecutarlos

Requiere [Node.js](https://nodejs.org) 14 o superior. Cada archivo es independiente:

```bash
node Saludo.js
```
