# Algoritmia - Semana 2

Ejercicios de **condicionales** (`if / else if / else`) y validación de datos en
**JavaScript** (Node.js).

| Archivo | Descripción |
|---|---|
| `anio_bisiesto.js` | Indica si un año es bisiesto |
| `semaforo.js` | Alerta de inventario: rojo, amarillo o verde |
| `validar_edad.js` | Concede o niega acceso según la edad |
| `validar_registro.js` | Registro permitido si edad >= 14 y acepta términos |
| `parqueadero.js` | Cobro de parqueadero (tarifas, tope, descuento y casos borde) |

## Cómo ejecutarlos

Requiere [Node.js](https://nodejs.org) 14 o superior. Cada archivo es independiente:

```bash
node anio_bisiesto.js
```
